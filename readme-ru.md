# Stadia Manager

[English](readme-en.md) · [فارسی](readme-fa.md) · **Русский**

> Менеджер геймпада Google Stadia для Windows — виртуальный геймпад Xbox 360

![Раздел Button Mapping](docs/button-mapping.png)

## Обзор

**Stadia Manager** — нативное приложение для Windows (Tauri v2), которое продолжает
использовать геймпад Google Stadia после закрытия Stadia. Оно читает реальный геймпад
через небольшой движок на C, позволяет переназначить любую кнопку и передаёт ввод в
игры как стандартный виртуальный геймпад **Xbox 360** через драйвер ViGEmBus — поэтому
любая игра, поддерживающая Xbox-геймпад, работает без дополнительной настройки.

Это настоящее настольное приложение: окно с иконкой в трее и установщик `.msi`/`.exe`,
а не веб-страница в оболочке.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **System Status** | Живой статус ViGEmBus, HidHide, ядра драйвера, мобильного сервиса, заряда батареи, типа подключения (USB/Bluetooth) и числа подключённых геймпадов. Установка/удаление драйверов в один клик. |
| **Button Mapping** | Переназначение всех 19 входов на фотографии геймпада, тремя режимами для каждой кнопки. |
| **Macros** | Запись многошаговых макросов (шаги `press` и `wait`) и запуск одной кнопкой. |
| **Vibration** | Тест вибрации и настройка её мощности. |
| **Remote Access** | Мини-HTTP-сервер (порт по умолчанию `9090`), чтобы телефон показывал статус и запускал вибрацию. |
| **Themes** | Пять цветовых тем (зелёная, синяя, голубая, оранжевая, фиолетовая). |
| **Tray** | Закрытие окна сворачивает его в трей; выход — из меню трея. |

## Раздел Button Mapping

![Раздел Button Mapping](docs/button-mapping.png)

На экране показана фотография вашего геймпада, и на каждой кнопке лежит метка (hotspot) —
всего 19: кнопки ромба, крестовина, бамперы, триггеры, нажатия стиков, а также Stadia,
Assistant, Capture, Options и Menu. Наведение на строку в списке подсвечивает и
увеличивает метку на фото (и наоборот), поэтому всегда видно, какую физическую кнопку
вы редактируете.

У каждой кнопки три режима назначения:

- **xinput** — отправить во виртуальный Xbox 360: `A`, `B`, `X`, `Y`, `Start`, `Back`,
  `Guide`, `LB`/`RB`, `LT`/`RT`, нажатия стиков или направления крестовины. Режим по
  умолчанию — именно его читают большинство игр.
- **app** — вместо ввода запустить программу (полный путь, например `C:\Games\game.exe`).
- **shortcut** — записать сочетание клавиш (например `Win + Shift + S`) и отправлять его
  при нажатии кнопки: удобно для скриншотов, Steam Overlay и системных клавиш.

Под фотографией расположены ползунки **Deadzone** для левого и правого стика и для
триггеров; они применяются к отчёту виртуального геймпада до отправки в игру.

## Как это работает

```
Геймпад Stadia (USB / Bluetooth)
        │  отчёты HID
        ▼
libstadia  (движок на C: src-tauri/csrc/libstadia)
        │  обнаружение устройств, входные отчёты, callback вибрации
        ▼
Ядро Rust / Tauri  (src-tauri/src)
        │  маппинг + макросы + конфиг + драйверы + трей + удалённый доступ
        ▼
Драйвер ViGEmBus  →  виртуальный Xbox 360  →  игры
```

- Движок на C (`hid.c`, `stadia.c`, `engine.c`, `utils.c`) компилируется крейтом `cc`
  в `build.rs` (только Windows) и общается с геймпадом по HID.
- Слой на Rust сопоставляет каждый отчёт согласно `config.json`, выполняет макросы,
  управляет виртуальным геймпадом через `vigem-client` и отдаёт команды Tauri в UI.
- Интерфейс — React + TypeScript + Tailwind; статус опрашивается каждые 2 секунды.

### Вибрация

Вибрация работает **только по USB**. Windows не может отправлять выходные отчёты
Stadia-геймпаду по Bluetooth, поэтому приложение честно сообщает об этом и просит
подключить геймпад кабелем.

### Драйверы

Приложение устанавливает два необходимых драйвера:

- [ViGEmBus](https://github.com/nefarius/ViGEmBus) — виртуальный геймпад Xbox 360
- [HidHide](https://github.com/nefarius/HidHide) — скрывает реальный геймпад от игр,
  чтобы ввод не дублировался

Установка предпочитает `winget` (`ViGEm.ViGEmBus`, `Nefarius.HidHide`) и, если его нет,
скачивает официальный установщик; в обоих случаях запуск повышается через UAC.

## Конфигурация

Настройки хранятся в `config.json` рядом с исполняемым файлом (путь показан в боковой
панели и открывается из приложения). Пример:

```json
{
  "system": { "runOnStartup": true },
  "vibration": { "strength": 100 },
  "deadzones": { "left": 10, "right": 10, "triggers": 5 },
  "mobile": { "enabled": false, "port": 9090 },
  "macrosEnabled": true,
  "keybinds": {
    "faceA":   { "mode": "xinput",   "value": "A",           "label": "Face A" },
    "captureBtn": { "mode": "shortcut", "value": "Win + Shift + S", "label": "Capture" },
    "stadiaBtn":  { "mode": "xinput",   "value": "Guide",      "label": "Stadia" }
  },
  "macros": [
    { "id": "rapid", "name": "Rapid Fire", "steps": [
      { "type": "press", "key": "RT", "ms": 50 },
      { "type": "wait",  "ms": 50 } ] }
  ]
}
```

## Требования

- Windows 10/11 x64
- Геймпад Google Stadia (кабель USB или сопряжение по Bluetooth)
- Драйверы ViGEmBus и HidHide (устанавливаются самим приложением)

## Разработка

Нужны: [Node.js](https://nodejs.org/) 20+, стабильный [Rust](https://rustup.rs/) и
[предварительные требования Tauri v2](https://v2.tauri.app/start/prerequisites/).

```bash
npm install

# только интерфейс (быстро, без Rust): http://localhost:1420
npm run dev

# полное настольное приложение с движком на C и ViGEm
cargo tauri dev
```

Проверки перед коммитом:

```bash
npx tsc --noEmit   # проверка типов
npm run build      # production-сборка интерфейса
```

## Сборка релизов

Релизы **никогда не собираются локально**. Достаточно запушить в `main` (или запустить
workflow вручную) — GitHub Actions соберёт их на `windows-latest` и опубликует
установщики `.msi` и `.exe` из воркфлоу **Build Windows Release**.

> Если Actions отключён на вашем аккаунте, сначала включите его в
> *Settings → Actions → General*, иначе workflow не запустится.

## Решение проблем

| Симптом | Решение |
| --- | --- |
| «No bus» в заголовке | Установите ViGEmBus в разделе *System Status*. |
| Геймпад не обнаруживается | Подключите по USB, нажмите кнопку Stadia, затем *Refresh devices*. |
| Ошибка вибрации про Bluetooth | Это нормально — подключите геймпад по USB. |
| Ввод приходит в игру дважды | Включите HidHide, чтобы физический геймпад был скрыт от игр. |
| Порт занят | Порт удалённого сервера настраивается (по умолчанию `9090`). |
